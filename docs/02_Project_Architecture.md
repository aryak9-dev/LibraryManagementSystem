# Project Architecture

```
LibraryManagement
│
├── Controllers
├── Models
├── Data
├── Views
├── wwwroot
├── docs
├── appsettings.json
└── Program.cs
```

---

## Folder Responsibilities

### Controllers

Handle incoming HTTP requests.

### Models

Represent database tables.

### Data

Contains LibraryContext.

### Views

Contains Razor Pages.

### wwwroot

Static files (CSS, JS, Images).

### docs

Project documentation.
