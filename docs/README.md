# Library Management System

## Overview

A Library Management System built using:

- ASP.NET Core MVC (.NET 9)
- Entity Framework Core
- MySQL
- Bootstrap

This project follows the provided PDF requirements while improving the project structure, UI, and code quality using industry best practices.

---

## Features

- Book Management (CRUD)
- Borrow Books
- Return Books
- Availability Tracking
- Validation
- Search
- Responsive UI

---

## Technology Stack

- ASP.NET Core MVC
- C#
- Entity Framework Core
- MySQL
- Bootstrap
